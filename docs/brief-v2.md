# 妈妈小店 · 微信小程序设计需求书 v2
> 用途：喂给 Claude / GPT 做 UI 细化设计与代码评审。v1 作废，以本版为准。
> 变更：① 支付改为铁律 ② "预览员"制度删除，改为完全无电脑流水线 ③ 分工明确到人

## 0. 一句话目标
给妈妈做一个在微信里卖洗碗布、洗洁精等日用品的小程序商城。买家是妈妈的微信熟人（街坊邻居、亲戚朋友），妈妈自己负责上架商品、处理订单。

## 1. 用户画像
- **妈妈（卖家）**：中老年，智能手机只会微信聊天、刷视频。后台必须极简：大字、大按钮，一页只做一件事，禁用专业术语（"SKU"→"商品"，"类目"→"分类"）。
- **买家**：妈妈的熟人，同样不一定懂网购。流程越短越好：看到商品 → 下单 → 填地址 → 付款，四步封顶。

## 2. 硬约束（违反任何一条方案作废）
1. **完全无电脑**：owner 没有电脑，朋友也不借。所有代码由 AI 在云 VM 上编写；
   真机预览不经过微信开发者工具，走云 VM 的 `miniprogram-ci` 生成预览二维码，owner 手机微信扫码即看（见 §8）。
2. **开发期零预算**：不允许任何付费服务、付费 SDK、付费模板。
3. **合规红线**：个人主体小程序**不能**开通微信支付、**不能**上架交易类目（微信硬性规则）。
   开发期用个人主体 + 测试数据；上线必须走"个体工商户"主体路线。
4. **商品是日用品**：洗碗布、洗洁精等，无需食品经营许可证，无需特殊资质。
5. **密钥铁律**：AppSecret、微信支付商户密钥/证书、小程序代码上传密钥，
   一律走云函数环境变量或云 VM 的 secrets 目录，**绝不写进代码、绝不进 Git 仓库**。

## 3. 技术选型（已定，不要换）
- **前端**：原生小程序（WXML + WXSS + JS）。不用 uni-app / Taro。
- **后端**：微信云开发（云数据库 + 云函数 + 云存储）。云函数 Node.js，前后端一种语言。
  开发期免费额度足够，不买服务器、不配域名。
- **工程链路**：`miniprogram-ci`（预览/上传）+ `@cloudbase/cli`（云函数部署），全部跑在云 VM 的 Linux 上。

## 5. 页面清单
### 买家端（5 个）
1. **首页**：商品流（图片+名称+价格）、顶部搜索框。SKU 很少，不做复杂分类。
2. **商品详情**：大图、价格、简单描述、"立即购买"按钮。
3. **下单页**：商品确认 + 收货地址 + 备注。
4. **订单列表**：按状态展示（待付款/待发货/已发货/完成），可看快递单号。
5. **我的**：联系卖家、妈妈后台入口（仅管理员可见）。
### 卖家后台（妈妈用，2 个）
6. **商品管理**：商品列表 + 新增/编辑（名称、价格、库存、图片）+ 上下架开关。
7. **订单管理**：新订单置顶 + 三个大按钮（确认收款/发货/完成），今日订单数、今日销售额两个大数字。

## 6. 数据模型（云数据库，4 张表）
- `products`：_id, name, price(分), stock, images[], desc, onSale(bool), createTime
- `orders`：_id, openid, items[{productId,name,price,qty}], total(分), address{name,phone,detail}, status(0待付款/1待发货/2已发货/3完成), expressNo, createTime
- `addresses`：_id, openid, name, phone, detail, isDefault
- `users`：_id, openid, nickName, avatar, isAdmin(bool)

## 7. 支付（铁律）
- **正式上线必须接微信支付**，这是门面，没得商量。
- **一期（开发期）**：个人主体，无微信支付商户号。`payMode='transfer'`：
  下单后页面提示买家微信转账给妈妈并备注订单号，妈妈在后台点"确认收款"→待发货。
- **二期（上线）**：两个前提缺一不可——
  ① 小程序主体转为**个体工商户**（营业执照免费办，owner 已满 18 岁可自行办理）；
  ② 开通**微信支付商户号**（交易手续费约 0.6%）。
  实现：云函数 `orderPrepay` 内调用微信支付 APIv3 统一下单（JSAPI），
  返回 `timeStamp/nonceStr/package/signType/paySign` 给前端 `wx.requestPayment`。
  商户号、APIv3 密钥、证书走云函数**环境变量**，绝不进仓库。
  前端 `app.globalData.payMode` 切到 `'wxpay'` 即可，前端流程不用改（代码已预留）。
- 金额一律用"分"存储，前端展示除以 100，杜绝浮点误差。

## 8. 测试方案（完全无电脑）
1. owner 在**手机浏览器**打开 `mp.weixin.qq.com` 注册小程序（主体选"个人"，免费；实名要身份证+人脸，手机上操作方便）。
2. 在小程序后台（开发 → 开发设置）拿到 **AppID**，下载**小程序代码上传密钥**发给 Miku（只放云 VM secrets 目录，不进仓库）。
3. Miku 在云 VM 跑 `node scripts/preview.js`（miniprogram-ci），生成 `preview-qr.png` 发给 owner。
4. owner 用**手机微信扫码**，直接打开开发版真机体验。全程不需要电脑、不需要微信开发者工具。
5. 云开发环境：owner 手机浏览器打开 `cloud.weixin.qq.com`，管理员微信扫码登录后创建环境，
   把环境 ID 告诉 Miku 填入 `app.js`；云函数由 Miku 用 cloudbase CLI 部署。
