# 妈妈小店 · UI 设计规范 v1

## 视觉方向
苹果式：大留白、大标题、大圆角、图片为主角、一个强调色。
**液态玻璃只用在“浮层”上**：顶部导航、悬浮 tabBar、详情页底栏、购物车结算条、弹层、主推商品图上的信息条。商品卡片和正文一律纯白实底，保证字看得清。
真正的折射效果小程序做不到，我们用“模糊 + 提亮饱和 + 半透明渐变 + 高光描边”近似，肉眼上很接近。每页最多 2~3 处玻璃，旧安卓机不卡。

## 色板
| 名称 | 色值 | 用途 |
|---|---|---|
| 雪白底 | `#F5F5F7` | 页面背景 |
| 纯白 | `#FFFFFF` | 卡片 |
| 墨黑 | `#1D1D1F` | 标题、正文、价格 |
| 石墨灰 | `#6E6E73` | 次要文字 |
| 苹果蓝 | `#0071E3` | 唯一强调色：主按钮、选中态 |
| 警示红 / 橙 / 绿 | `#FF3B30` / `#FF9500` / `#34C759` | 角标·删除 / 待付款·仅剩 / 上架中 |

价格不用红色，用墨黑加粗，保持克制。

## 字体与字号
字体栈：`-apple-system, SF Pro Text, PingFang SC`（iOS 自带，安卓自动回退）。

| 买家端 | 字号 | 字重 |
|---|---|---|
| 大标题 | 68rpx | 700 |
| 详情页价格 | 60rpx | 700 |
| 商品名（详情） | 46rpx | 700 |
| 正文 / 按钮 | 30~32rpx | 400 / 600 |
| 辅助说明 | 24~28rpx | 400 |
| **最小字号** | **22rpx**（仅 tabBar 文字） | 600 |

## 圆角（嵌套递减）
主推大图 48 · 卡片 40 · 地址/信息块 28~32 · 缩略图 22~28 · 按钮、胶囊 全圆。

## 动效
只在“用户操作有反应”时出现：按压缩放 0.96、分段控件滑块、tabBar 选中底、弹层滑入、轮播圆点伸缩。没有进场动画，没有无意义的循环动画。

## 妈妈后台规范（回答需求书 §10-2）
同一套苹果风，**换成大字、高对比、纯色实底，不用玻璃**。
- 正文最小 **32rpx**，订单号/商品名 **36~40rpx**，数字 **80rpx**
- 按钮高 **120rpx**，文字 **44rpx**，全宽
- 一个订单只露出**一个**大按钮，按钮上写的就是下一步要做的事：确认收款 → 发货 → 完成
- 不出现“SKU”“类目”等术语；状态用“文字 + 底色”双重表达，不靠颜色单独区分
- 危险或不可逆操作（确认收款、完成订单）一律先弹确认框
- 发货时除了填快递单号，还可以一键选“同城送货”“上门自提”（回答需求书 §10-4：两种都支持）

## 商品拍照小贴士（回答需求书 §10-3，已内置在“新增商品”页）
1. 靠近窗户拍，用白天的自然光，不要开闪光灯。
2. 下面垫一张白纸或干净的桌面，背景越简单越好。
3. 商品放在画面正中间，占满三分之二，系统会自动裁成正方形。
4. 拍之前擦一下镜头，两只手拿稳，再点拍照。
5. 多拍几张：整体一张，细节或包装一张，使用时的样子一张。
